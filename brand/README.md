# Brand assets

Logo "IT mit Kopf" (vector, text converted to paths, no font needed at runtime).

- `public/assets/img/logo-color.svg` – main logo, works on light and dark backgrounds
- `public/assets/img/favicon.svg` – icon (red "IT" + three paint dots)
- `public/assets/img/bimi.svg` – square variant in SVG Tiny-PS style for a BIMI record (not validated)
- `brand/make_logo2.py` – generator (needs `fonttools`, the font *Rubik Wet Paint*, SIL OFL 1.1, from google/fonts)
- `brand/prev.py` – renders `preview.png` (needs `resvg_py`)
